📦 Box Set Migration

CineShelf v2.3.0 Database Update

What This Does:

This migration adds support for multi-movie containers (box sets, double features, trilogy packs).

  • Creates containers table
  • Creates container_contents table
  • Updates shelf_assignments table
  • Creates containers_with_counts view
  • Adds indexes for performance

⚠️ Important:

This migration is safe to run multiple times. If tables already exist, it will skip them.

No existing data will be affected.
