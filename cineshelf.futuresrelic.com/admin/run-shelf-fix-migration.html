🔧 Fix Shelf Assignments Schema

This migration fixes the shelf_assignments table to properly support box sets/containers by making the copy_id column nullable.

This migration will:
  • Make copy_id nullable (currently NOT NULL)
  • Add CHECK constraint to ensure data integrity
  • Preserve all existing shelf assignments
  • Enable proper container assignment to shelves
⚠️ Important: This will rebuild the shelf_assignments table. While existing data will be preserved, it's recommended to only run this once.
