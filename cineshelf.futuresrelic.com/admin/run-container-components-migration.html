📋 Container Components Migration

CineShelf v2.9.0 Database Update

What This Does:

Adds the box set component checklist system — track what's in the box for each of your box sets.

  • Creates container_components table (what UMDB says comes in the box)
  • Creates copy_container_components table (what you actually have)
  • Adds indexes for performance

✅ After This Migration:

Box set detail pages will show a "What's in the Box" checklist. Sync from UMDB to auto-populate components, or add them manually.

⚠️ Safe to Run:

This migration is safe to run multiple times. If tables already exist, it will report that and skip.
