Data Management

UMDB Sync

Three-phase sync: physical editions → box sets → individual films (not in box sets). Already-synced items are skipped. Safe to run multiple times. Open browser console (F12) after sync for a full item-by-item audit report. Use Force Resync after clearing UMDB — clears all stored IDs locally and re-pushes all box sets and individual films.

👋 Welcome to CineShelf!

Your personal library for every disc you own. Here's how to get started:

🎬
Add films to your collection Tap + and search any title. Add physical copy details — format, edition, barcode — to build your real shelf.
📋
Build a wishlist Save films you want to own. Import an entire top-10 article at once with the web scraper.
📲
Install as an app CineShelf works offline. Go to Settings → Install App to add it to your home screen.
🔗
Share your collection Enable a public link in Settings → Public Collection so anyone can browse your shelf.
