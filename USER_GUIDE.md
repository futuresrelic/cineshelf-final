## Getting Started

### What is CineShelf?

CineShelf helps you organize and manage your physical movie collection (DVDs, Blu-rays, 4K UHDs, etc.). Whether you have 10 movies or 1,000, CineShelf makes it easy to:

- **Track what you own** - Know exactly which movies you have and where they are
- **Build a wishlist** - Remember which movies you want to buy
- **Share with family** - Create groups to see everyone's collections together
- **Lend and borrow** - Keep track of who has which movies
- **Play trivia** - Test your knowledge of your collection
- **Find movies fast** - Search, sort, and filter your library

### Creating Your Account

1. **Visit CineShelf**
   - Go to: `https://cineshelf.futuresrelic.com`

2. **Sign In with Google**
   - Click "Sign in with Google"
   - Choose your Google account
   - Grant permissions

3. **You're In!**
   - Your account is created automatically
   - Your email and profile picture are saved
   - You can now start adding movies

### Installing CineShelf as an App

CineShelf is a Progressive Web App (PWA), which means you can install it on your device:

**On Desktop (Chrome, Edge):**
1. Click the ⊕ install icon in the address bar
2. Or: Menu → "Install CineShelf"
3. App appears in your applications

**On iPhone/iPad:**
1. Open in Safari
2. Tap the Share button
3. Tap "Add to Home Screen"
4. Tap "Add"

**On Android:**
1. Open in Chrome
2. Tap Menu (⋮)
3. Tap "Install app" or "Add to Home screen"

**Benefits of Installing:**
- Works offline
- Faster loading
- App icon on your device
- Full-screen experience

## Your Collection

### Adding Movies: Single vs Box Set

When adding to your collection, you have two options:

**Single Movie** - For individual DVDs/Blu-rays
**Box Set** - For multi-movie collections in one physical case

### Adding Your First Movie

1. **Go to Add Tab**
   - Click the ➕ "Add" tab in navigation

2. **Choose Add Type**
   - **Add Single Movie** - For individual discs
   - **Add Box Set** - For multi-movie collections (trilogies, double features, etc.)

#### Adding a Single Movie

1. **Click "Add Single Movie"**
   - The search dialog opens

2. **Search for Movie**
   - Type the movie title (e.g., "Inception")
   - Results appear as you type
   - Click the correct movie

4. **Enter Details**
   - **Format**: DVD, Blu-ray, 4K UHD, VHS, Laserdisc, etc.
   - **Edition**: Standard, Special Edition, Director's Cut, etc.
   - **Region**: Region 1-6, Region A/B/C, or All Regions
   - **Condition**: Mint, Good, Fair, or Poor
   - **Location**: Where you store it (e.g., "Living Room Shelf")
   - **Purchase Date**: When you got it (optional)
   - **Purchase Price**: How much you paid (optional)
   - **Notes**: Any additional info

5. **Click "Add to Collection"**
   - Movie appears in your collection
   - Poster and metadata are saved automatically

### Understanding Movie Information

Each movie in your collection shows:

- **Poster** - Automatically fetched from TMDB
- **Title** - Official movie title
- **Year** - Release year
- **Director** - Who directed it
- **Rating** - TMDB community rating (0-10)
- **Genre** - Movie categories
- **Certification** - Content rating (G, PG, PG-13, R, NC-17)
- **Runtime** - Length in minutes
- **Format** - Your physical format (DVD, Blu-ray, etc.)
- **Edition** - Special edition info
- **Condition** - Disc/case condition

### Viewing Your Collection

**Grid View** (Default)
- Large posters in a grid
- Easy to browse visually
- Great for discovering movies

**List View**
- Compact rows with details
- See more movies at once
- Better for searching specific info

**Switch Views:**
- Click the Grid (⊞) or List (☰) icon at the top

### Searching Your Collection

Use the search box to find movies by:
- **Title** - Type any part of the title
- **Director** - Find all movies by a director
- **Actor** - Search by cast member
- **Year** - Find movies from a specific year

**Example Searches:**
- "Nolan" → All Christopher Nolan movies
- "1999" → All movies from 1999
- "Matrix" → The Matrix trilogy
- "Spielberg" → All Spielberg films

### Sorting Your Collection

Click the sort dropdown to order by:

- **Title (A-Z)** - Alphabetical
- **Title (Z-A)** - Reverse alphabetical
- **Year (Newest)** - Most recent first
- **Year (Oldest)** - Oldest first
- **Rating (Highest)** - Best rated first
- **Rating (Lowest)** - Lowest rated first
- **Recently Added** - Last added first

### Filtering Your Collection

Use filters to show only specific movies:

**By Format:**
- DVD only
- Blu-ray only
- 4K UHD only
- Custom formats

**By Genre:**
- Action, Comedy, Drama, Horror, etc.
- Multi-select to combine genres

**By Rating:**
- G, PG, PG-13, R, NC-17
- Filter family-friendly movies

**By Year Range:**
- 1980s, 1990s, 2000s, etc.
- Custom year ranges

**By Director:**
- See all movies by your favorite directors
- Quick director filter from movie card

**By Shelf (NEW in v2.2.14):**
- Filter collection by physical shelf location
- Located in dropdown before Sort dropdown
- Shows "All Movies" by default
- Select any shelf to see only movies on that shelf
- **Hierarchical Support** - Parent shelves show all movies from child shelves
  - Example: "Directors" shelf shows all movies from "Kubrick", "Tarantino", and "Spielberg" child shelves
- Duplicates automatically removed
- Sorting and view modes still work while filtered

**How to Use Shelf Filtering:**
1. Go to Collection tab
2. Click the first dropdown (shows "All Movies")
3. Select a shelf (e.g., "Disney Collection")
4. Collection view updates to show only movies on that shelf
5. Select "All Movies" to see full collection again

### Editing a Movie

1. **Click the Movie Card**
   - Opens movie details

2. **Click "Edit"**
   - Edit form appears

3. **Change Details**
   - Update format, edition, condition, etc.
   - Change poster (if multiple available)
   - Customize display title

4. **Save Changes**
   - Click "Save"
   - Updates immediately

### Changing the Poster

If you don't like the default poster:

1. **Open Movie Details**
2. **Click "Change Poster"**
3. **Browse Available Posters**
   - TMDB provides multiple poster versions
   - Different languages, styles, editions
4. **Click a Poster to Select It**
5. **Save**

### Customizing Movie Title

Want to display a movie differently? (e.g., "Star Wars Episode IV" instead of "Star Wars")

1. **Open Movie Details**
2. **Click "Edit Display Title"**
3. **Enter Your Preferred Title**
4. **Save**

Original title is preserved; only display changes.

### Removing a Movie

1. **Click the Movie Card**
2. **Click "Delete"**
3. **Confirm**
   - Movie removed from your collection
   - Does NOT affect other users

**Note:** This only removes YOUR copy. The movie data (poster, metadata) stays in the database for other users.

## Box Sets & Multi-Movie Collections

### What are Box Sets?

Box sets are physical cases containing multiple movies. Examples:
- **Trilogy Box Sets** - Lord of the Rings Extended Edition (3 movies, 1 case)
- **Double Features** - Alien / Aliens (2 movies, 1 case)
- **Complete Collections** - James Bond Collection (25 movies, 1 box)
- **Franchise Sets** - Marvel Phase 1 Collection (6 movies, 1 box)

### Why Use Box Sets?

**Benefits:**
- ✅ Accurate shelf representation (shows as ONE spine, not 3+)
- ✅ Track movies individually in your collection
- ✅ Organize related movies together
- ✅ Know what's in each physical case
- ✅ Track missing discs if you lend one out

### Creating a Box Set

**Step 1: Define the Box Set**

1. **Go to Add Tab** (➕)
2. **Click "Add Box Set"**
3. **Enter Box Set Details:**
   - **Name**: Full name (e.g., "The Matrix Trilogy")
   - **Spine Label**: What appears on physical spine (e.g., "THE MATRIX TRILOGY")
   - **Format**:
     - Blu-ray Box Set
     - DVD Box Set
     - 4K UHD Box Set
     - Mixed Format
   - **Condition**: Mint, Like New, Good, Fair, Poor
   - **Notes**: Edition details (e.g., "Ultimate Collector's Edition")
4. **Click "Create Box Set"**

**Step 2: Add Movies**

1. **Search for First Movie**
   - Type movie title in search box
   - Results appear from TMDB

2. **Click Movie to Add**
   - Movie added to box set
   - Shows in list below with poster

3. **Repeat for All Movies**
   - Add all movies in the box set
   - They appear in order as you add them

4. **View Box Set Details**
   - Click "View Box Set Details" to see what you've added
   - Shows all movies with posters
   - Can edit or delete from here

5. **Finish**
   - Click "Done" or navigate away
   - Box set is saved automatically

### Example: Creating The Matrix Trilogy Box Set

```
Step 1: Create Box Set
├─ Name: The Matrix Trilogy
├─ Spine Label: THE MATRIX TRILOGY
├─ Format: Blu-ray Box Set
└─ Condition: Mint

Step 2: Add Movies
├─ Search "The Matrix" → Add (1999)
├─ Search "Matrix Reloaded" → Add (2003)
├─ Search "Matrix Revolutions" → Add (2003)
└─ Click "View Box Set Details" → Done!
```

### Viewing Box Sets in Your Collection

**Collection Tab:**
- Movies show individually with their posters
- Each movie displays "📦 Part of [Box Set Name]"
- Click box set name to see all movies in that box set

**Example:**
```
┌─────────────────────┐
│  [Matrix Poster]    │
│  The Matrix         │
│  1999 | ⭐ 8.7      │
│  📦 The Matrix      │ ← Click to view box set
│     Trilogy         │
│  Disc 1 of 3        │
└─────────────────────┘
```

### Editing a Box Set

**Add More Movies:**

1. **Find Box Set** in Collection tab
   - Look for movies with 📦 badge
   - Click box set name

2. **Click "Edit" Button**
   - Opens in Add tab
   - Shows existing movies
   - Labeled "(Editing)" at top

3. **Add More Movies**
   - Search and add just like creation
   - New movies appear in list

4. **Save Changes**
   - Click "Done" or navigate away
   - All movies saved automatically

**Edit Box Set Details:**

1. **Open Box Set Details Modal**
   - Click 📦 badge on any movie in the set
   - Or find in Collection and click "View Details"

2. **Click "Edit Box Set"**
3. **Change Details:**
   - Name, format, condition, notes
4. **Save**

### Deleting a Box Set

**Important:** Deleting a box set removes the container but KEEPS all movies in your collection as individual items.

1. **Open Box Set Details**
2. **Click "Delete Box Set"**
3. **Confirm**
   - Box set removed
   - Movies remain in collection
   - Movies no longer grouped

### Box Set Tips

**Organizing Large Collections:**
- Create box sets for franchises (Star Wars, Marvel, etc.)
- Use spine labels that match physical cases
- Add notes about special features or editions

**Tracking Borrowed Discs:**
- When you lend Disc 2 to a friend, the movie stays in your collection
- In future versions, you'll be able to mark individual discs as "borrowed"

**Box Set + Shelves:**
- Assign box set to a shelf as ONE unit
- On visual shelf view, shows as single spine
- Badge shows number of movies (e.g., "3 movies")

**Common Use Cases:**
1. **Trilogy**: 3 movies, 1 spine
2. **Double Feature**: 2 movies, 1 spine
3. **Complete Series**: All movies in franchise
4. **Director Collections**: All films by one director
5. **Genre Packs**: Horror collection, Comedy collection, etc.

### Collection Statistics

See your collection stats at the top:

- **Total Movies** - Number of unique titles
- **Total Copies** - Number of physical items
- **Total Value** - Sum of purchase prices
- **Formats Breakdown** - How many DVDs, Blu-rays, etc.
- **Average Rating** - Average TMDB rating of your collection

## Managing Your Wishlist

### Adding Movies to Your Wishlist

Movies you want to buy but don't own yet.

1. **Search for Movie**
   - Same as adding to collection

2. **Click "Add to Wishlist"**
   - Instead of "Add to Collection"

3. **Set Priority** (1-10)
   - 10 = Must have immediately
   - 5 = Would like to have
   - 1 = Maybe someday

4. **Set Target Format**
   - Preferred format you want to buy

5. **Set Max Price**
   - Maximum you're willing to pay

6. **Add Notes**
   - Reminders (e.g., "Wait for sale", "Check eBay")

### Viewing Your Wishlist

1. **Click "Wishlist" Tab**
2. **See All Wishlisted Movies**
   - Sorted by priority (highest first)
   - Shows target format and max price

### Buying a Wishlisted Movie

When you finally buy it:

1. **Click the Movie in Wishlist**
2. **Click "Add to Collection"**
3. **Enter Purchase Details**
4. **Save**
   - Automatically removed from wishlist
   - Added to collection

### Removing from Wishlist

Changed your mind?

1. **Click the Movie in Wishlist**
2. **Click "Remove from Wishlist"**
3. **Confirm**

## Playing Trivia

Test your movie knowledge!

### Game Modes

**Sprint Mode:**
- 10 questions
- 60 seconds per question
- Race against the clock
- Perfect for quick games

**Endless Mode:**
- Keep going until you get one wrong
- No time limit
- See how long you can last
- Build up score multipliers

**Survival Mode:**
- 3 lives
- Lose a life for each wrong answer
- No time limit
- Survive as long as possible

### Question Scopes

Choose what movies to quiz on:

**Your Collection:**
- Only movies you own
- Great for testing what you remember

**Your Wishlist:**
- Movies you want to buy
- Learn before you own them

**All Movies:**
- Entire CineShelf database
- Challenging mode

**Mix (50/50):**
- Half from your collection
- Half from all movies
- Balanced difficulty

### Starting a Game

1. **Click "Trivia" Tab**
2. **Choose Game Mode**
   - Sprint, Endless, or Survival
3. **Choose Scope**
   - Collection, Wishlist, All, or Mix
4. **Click "Start Game"**

### Question Types

Questions get harder as you progress:

**Easy (Rounds 1-5):**
- What year was [movie] released?
- Who directed [movie]?
- What genre is [movie]?
- What's the runtime of [movie]?
- What's the certification of [movie]?

**Medium (Rounds 6-15):**
- Which came out first: [A] or [B]?
- Which is longer: [A] or [B]?
- Which has higher rating: [A] or [B]?
- Who starred in [movie]?
- What franchise is [movie] from?

**Hard (Round 16+):**
- Which movie has this plot?
- Who said this quote?
- Which actor appeared in both movies?
- Complex director/cast questions
- Rare trivia facts

### Answering Questions

- **Multiple Choice** - Click an answer
- **Timer** - Watch the clock (Sprint mode only)
- **Streak** - Consecutive correct answers
- **Points** - Base points + speed bonus + streak multiplier

### Scoring System

**Base Points:**
- Easy question: 100 points
- Medium question: 200 points
- Hard question: 300 points

**Speed Bonuses (Sprint mode):**
- Under 5 seconds: +50 points
- Under 10 seconds: +30 points
- Under 15 seconds: +10 points

**Streak Multipliers:**
- 3 in a row: 1.5x points
- 5 in a row: 2.0x points
- 10 in a row: 3.0x points

**Example:**
- Hard question (300 pts)
- Answered in 4 seconds (+50 bonus)
- 5-question streak (2.0x multiplier)
- Total: (300 + 50) × 2.0 = **700 points**

### Viewing Your Stats

After each game:

- **Score** - Total points earned
- **Accuracy** - Percentage correct
- **Best Streak** - Longest correct run
- **Time** - How long you played

**All-Time Stats:**
- Total games played
- Best score ever
- Longest streak ever
- Questions by difficulty
- Win rate (Sprint mode)

### Leaderboards

**Personal Stats:**
- Your best scores
- Your progress over time

**Group Leaderboard:**
- Compete with group members
- See who knows movies best

**Global Leaderboard:**
- All CineShelf users
- Top scores by mode

## Frequently Asked Questions

### General Questions

**Q: Is CineShelf free?**
A: Yes! CineShelf is completely free to use.

**Q: Do I need a Google account?**
A: Yes, currently CineShelf uses Google OAuth for authentication.

**Q: Can I use it offline?**
A: Yes, as a PWA, CineShelf works offline after first load. However, adding new movies requires internet (TMDB lookup).

**Q: What about TV shows?**
A: CineShelf focuses on movies, but TV show support is being improved.

**Q: Is my data private?**
A: Yes, only you can see your collection unless you join a group. Group members only see what you explicitly share.

### Collection Questions

**Q: Can I add the same movie twice?**
A: Yes! If you own multiple formats (DVD + Blu-ray), add separate copies.

**Q: What if a movie isn't in TMDB?**
A: Rare/obscure movies can be added manually to the "Resolve" queue. Admins can match them later.

**Q: Can I add custom formats?**
A: Yes, type any format name (VHS, Laserdisc, Betamax, etc.)

**Q: Can I upload my own poster?**
A: Not yet, but you can choose from multiple TMDB posters.

**Q: How do I track box sets?**
A: Add each movie individually, use edition field for "Lord of the Rings Extended Box Set"

### Group Questions

**Q: How many people can join a group?**
A: No limit! Families, friend groups, movie clubs welcome.

**Q: Can I be in multiple groups?**
A: Yes, join as many as you want.

**Q: What if someone doesn't return a movie?**
A: CineShelf tracks this but doesn't enforce. Handle personally with the borrower.

**Q: Can I hide my collection from a group?**
A: No, joining a group shares your collection with all members. Leave the group to make it private again.

### Trivia Questions

**Q: Where do questions come from?**
A: Generated from your collection's metadata (TMDB data).

**Q: Can I submit custom questions?**
A: Not yet, but planned for future updates.

**Q: Do I compete against others?**
A: Leaderboards show rankings, but games are single-player.

### Technical Questions

**Q: What browsers work best?**
A: Chrome, Firefox, Safari, Edge (latest versions)

**Q: What about Internet Explorer?**
A: Not supported. Please use a modern browser.

**Q: Can I sync across devices?**
A: Yes! Log in with the same Google account on any device.

**Q: How do I report a bug?**
A: Contact your administrator or check the GitHub repository.

## Troubleshooting

### Login Issues

**Problem: Can't log in with Google**

Solutions:
1. Clear browser cookies
2. Try incognito/private mode
3. Check internet connection
4. Verify you're using the correct Google account
5. Disable browser extensions temporarily

**Problem: "Session expired" error**

Solutions:
1. Log out completely
2. Clear cookies
3. Log back in
4. Sessions last 30 days, then need to re-login

### Collection Issues

**Problem: Movies not appearing**

Solutions:
1. Refresh the page (Ctrl/Cmd + R)
2. Check filters - you might be filtering them out
3. Check sort order
4. Clear cache and reload

**Problem: Poster images not loading**

Solutions:
1. Check internet connection
2. Clear browser cache
3. Try different browser
4. Wait a few minutes (TMDB might be slow)

**Problem: Can't add a movie**

Solutions:
1. Check spelling of title
2. Try searching by year: "Inception 2010"
3. Check if already in collection
4. Try searching TMDB directly to verify it exists

### Group Issues

**Problem: Can't see group collection**

Solutions:
1. Verify you accepted the invitation
2. Check you're viewing the correct group
3. Refresh the page
4. Check if group admin removed you

**Problem: Invitation not working**

Solutions:
1. Verify email matches Google account
2. Check spam folder for invitation email
3. Ask admin to resend invitation
4. Try accepting from different browser

### Trivia Issues

**Problem: Questions repeat**

Solutions:
1. This is normal with small collections
2. Expand scope to "All Movies"
3. Add more movies to your collection

**Problem: Score not saving**

Solutions:
1. Make sure you clicked "Finish Game"
2. Check internet connection
3. Try playing again
4. Stats update after game completion

### Performance Issues

**Problem: App is slow**

Solutions:
1. Close other browser tabs
2. Clear browser cache
3. Disable browser extensions
4. Update your browser
5. Restart browser

**Problem: App won't install**

Solutions:
1. Use supported browser (Chrome, Edge, Safari)
2. Check if already installed
3. Enable "Install apps" in browser settings
4. Try from desktop (some mobile browsers limit PWA)

### Data Issues

**Problem: Lost data**

Solutions:
1. Log in with same Google account
2. Check if logged into correct account
3. Contact administrator for backup restore
4. Export data regularly as backup

**Problem: Duplicate movies**

Solutions:
1. Use search to find duplicates
2. Delete unwanted copy
3. Keep the one with most complete info
